# TEMNOTA II: SIXXXSEVEN

Статический лендинг для публикации на обычный хостинг без сборки.

## Что внутри

- `index.html` — структура страницы
- `styles.css` — стили и адаптив
- `script.js` — таймер до события
- `poster.png` — афиша

## Перед публикацией

1. Замени ссылку на билеты `http://google.com/` в `index.html` на реальную.
2. Если нужно, обнови дату события в `index.html` и `script.js`.
3. При желании замени `poster.png` на другую афишу с тем же именем.

## Как загрузить на хостинг

Загрузи в корень сайта эти файлы:

- `index.html`
- `styles.css`
- `script.js`
- `poster.png`

После этого привяжи домен к хостингу через DNS-записи у регистратора домена.
